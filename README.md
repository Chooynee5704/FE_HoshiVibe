# HoshiVibe

Modern ecommerce frontend for feng shui jewelry with AI-assisted custom design.

Live demo: https://fe-hoshi-vibe.vercel.app/

## Highlights
- Product catalog, search, and detailed product pages
- AI-enhanced custom jewelry design studio
- Cart, checkout, orders, and user profile flow
- Admin dashboard for product, order, and customer management
- Responsive UI with polished interactions

## Tech Stack
- React 19, TypeScript, Vite (rolldown)
- Ant Design, Tailwind CSS
- Recharts, Swiper
- Axios
